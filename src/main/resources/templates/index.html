How Sarvam generation works

Sarvam is prompted for established names used in the selected language, conventional English spellings, and short meanings. The app checks the returned language/gender labels and prefix, removes duplicates, and calculates the pyramid number in Java. These labels and meanings are generated by AI and should be checked before choosing a name.

Large requests use up to 14 concurrent batches of 50 and retain completed Sarvam results in the persistent database. This does not use offline or invented names. The default Sarvam response budget is 28 seconds, and the actual count can be below 500 if Sarvam is slow, returns duplicates or runs out of suitable names. Repeating a search can reuse all previously saved names. Sarvam output varies by language, gender, prefix and account quota. The final number filter reduces the candidate list further.
